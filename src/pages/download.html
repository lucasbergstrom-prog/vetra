Installing

Four steps, about a minute.

  1. Run the installer

    Open {{installer_file}} from your Downloads folder.

  2. Pass the Windows warning

    Windows may say "Windows protected your PC" because this test version is not code-signed yet. Click More info, then Run anyway.

  3. Take the tour

    The first time VETRA opens it offers a guided tour on practice photos. You can take it again from the ? menu.

  4. Add the AI models, if you like

    The first time you use a Subject mask or Lens blur, VETRA asks before downloading the models it needs.

Verify

Check that the file is genuine.

Because the installer is unsigned, the checksum is how you confirm that the file you have is the one published here. Run this in PowerShell from the folder you downloaded to:

Get-FileHash .\{{installer_file}} -Algorithm SHA256

The hash it prints should match this one exactly, ignoring upper and lower case:

{{installer_sha256}}

If it does not match, do not run the file. Delete it and download again from this page.

Good to know

  • Upgrading. Run the new installer over the old version. Your library, settings and edits are kept.
  • What VETRA downloads. Only the optional AI models, from Hugging Face and PyTorch, and only after asking. Nothing else. Privacy details.
  • Where it keeps things. Edits sit beside each photo as .vetra.json files. The library, settings and logs are in %USERPROFILE%\.vetra.
  • Removing it. Windows Settings › Apps › VETRA › Uninstall. It asks before deleting your library and settings; photos and their edit files are never touched.
